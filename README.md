# E-Commerce API

A scalable, multi-seller e-commerce backend for the health & beauty market (cosmetics and pharmacy retail), built with Node.js, Express, and PostgreSQL (Prisma ORM). Designed API-first so the same backend can power a web storefront, seller dashboard, admin panel, and mobile app without changes.

Built as a portfolio and open-source project and used in production for a real retail business.

**Status:** in active development — see [BUILD_LOG.md](./BUILD_LOG.md) for weekly progress.

## Stack
- Node.js + Express
- PostgreSQL + Prisma
- JWT authentication
